# Taleela v8.12.0 — Premium Game UI

Visual redesign based on the approved dark-purple quiz-show concept.

- Desktop gameplay uses a dedicated player rail, central stage, round progress tracker, and prominent circular timer.
- Mobile gameplay collapses the player rail to a compact horizontal strip and keeps answers single-column.
- Lobby uses a dashboard layout on wide screens and a stacked layout on mobile.
- Room compositor-stability rules from v8.11.2 are preserved (no dynamic lobby backdrop blur or tap transforms).
- Game logic, scoring, Firebase schema, question selection, and question bank are unchanged.
