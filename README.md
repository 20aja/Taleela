# Taleela — تعليلة v8.1.0 (Lazy Question Shards)

هذه النسخة مبنية فوق v8.0.0 Performance Stage 1 وتحوّل بنك الأسئلة من ملف JavaScript واحد إلى ملفات JSON مجزأة تُحمّل عند الحاجة فقط.

## ما تغير في v8.1.0

- حذف `js/questions.js` من التطبيق المنشور.
- إضافة `js/question-store.js` لإدارة تحميل الأسئلة.
- إضافة `questions/v8.1.0/manifest.json` صغير يصف الفئات والملفات.
- تقسيم 10,924 سؤالًا إلى 81 ملف JSON، بحد أقصى 200 سؤال تقريبًا لكل ملف.
- اللاعبون العاديون لا يحملون بنك الأسئلة.
- المضيف يحمل Manifest فقط عند بدء المباراة، ثم ملفًا واحدًا من الفئة المختارة عند الحاجة.
- يبقى ملف الفئة الجزئي في الذاكرة وCache، لذلك الجولات التالية لا تنتظر الشبكة غالبًا.
- منع تكرار السؤال داخل الغرفة حتى نفاد أسئلة الفئة.
- حفظ دورة محلية على جهاز المضيف لتقليل تكرار الأسئلة بين المباريات أيضًا.
- ملفات الأسئلة Versioned وImmutable في Netlify/Firebase Hosting.

## Firestore

بنية Firestore وقواعد v8.0.0 لم تتغير. لا تحتاج إلى تعديل `firestore.rules` عند الانتقال من v8.0.0 إلى v8.1.0.

راجع `QUESTION_BANK_INFO.md` و`DEPLOYMENT.md` و`TESTING.md`.
