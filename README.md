# Taleela — تعليلة v8.10.0

لعبة أسئلة جماعية عربية تعمل بالغرف باستخدام JavaScript ES Modules وFirebase Authentication وCloud Firestore، مع دعم PWA.

## بنك الأسئلة النشط

- المصدر الوحيد للأسئلة: `questions/v1/`.
- العدد: **600 سؤال**.
- الفئات: **20 فئة**.
- كل فئة تحتوي على 30 سؤالًا موزعة كما وردت في الملف المرفق على ثلاثة Shards.
- لم تُضف أسئلة جديدة، ولم يُعدّل نص أو جواب أو خيار داخل ملفات JSON.
- تم حذف البنوك السابقة وملف `js/questions.js` القديم من نسخة المشروع النظيفة.

## الأعلام

- أعلام الدول موجودة في `assets/countries/`.
- فئة `flags` تستخدم صور الأعلام المحددة أصلًا داخل بنك الأسئلة.
- فئة `countries` تعرض علم الإجابة عند مرحلة الكشف فقط، حتى لا يكشف العلم الإجابة قبل التصويت.
- ربط أعلام فئة `countries` مشتق وقت التشغيل من بيانات فئة `flags`؛ ملفات الأسئلة نفسها لم تُعدّل.

## منع تكرار الأسئلة

الاختيار يعمل دون إرجاع داخل كل فئة:

1. تحتفظ الغرفة في Firestore بمعرّفات الأسئلة المستخدمة في الدورة الحالية لكل فئة.
2. لا يُعاد أي معرّف سؤال في الفئة قبل استهلاك جميع أسئلتها الثلاثين.
3. بعد السؤال الثلاثين تبدأ دورة جديدة لتلك الفئة وحدها.
4. لا تُمسح دورة الأسئلة عند إعادة اللعب أو الرجوع إلى غرفة الانتظار.
5. يحتفظ جهاز المضيف بسجل محلي إضافي عبر `localStorage` لتقليل التكرار أيضًا عند إنشاء غرف جديدة.
6. عند انتقال المضيف، يبقى سجل الغرفة هو المرجع الأعلى، لذلك لا يعيد المضيف الجديد سؤالًا ظهر في دورة الغرفة الحالية.
